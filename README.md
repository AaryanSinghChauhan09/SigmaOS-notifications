# SigmaOS Notifications

Unified notification daemon for SigmaOS with libnotify compatibility.

## Overview

SigmaOS Notifications provides a unified notification system for SigmaOS, compatible with libnotify for integration with existing applications.

## Features

- Unified notification daemon
- libnotify compatibility
- SigmaOS theming
- Notification history
- Urgency levels
